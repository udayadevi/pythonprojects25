
# 🐍 Python Beginner Projects

This repository contains **15 beginner-friendly Python projects** to help new learners build confidence, practice programming logic, and understand Python fundamentals.  
Each project is small, simple, and focuses on a core Python concept.

---

## 📘 List of Projects

### 1️⃣ BMI Calculator
Calculates Body Mass Index based on user input for weight and height.  
**Learned concepts:** Input, arithmetic, conditionals

### 2️⃣ Sum of an Array
Adds all numbers in a list.  
**Learned concepts:** Lists, loops, math operations

### 3️⃣ Rock–Paper–Scissors Game
Play against the computer’s random choice.  
**Learned concepts:** Random module, conditionals, loops

### 4️⃣ Number Guessing Game
Guess the computer’s random number with hints.  
**Learned concepts:** Random numbers, loops, comparison

### 5️⃣ Even/Odd Checker
Checks whether a number is even or odd.  
**Learned concepts:** Conditionals, arithmetic

### 6️⃣ Palindrome Checker
Checks if a string or number reads the same forwards and backwards.  
**Learned concepts:** Strings, conditionals, loops

### 7️⃣ Calculator
Simple calculator supporting addition, subtraction, multiplication, and division.  
**Learned concepts:** Functions, input, arithmetic

### 8️⃣ Factorial Calculator
Calculates the factorial of a number.  
**Learned concepts:** Loops, recursion (optional)

### 9️⃣ Temperature Converter
Converts between Celsius and Fahrenheit.  
**Learned concepts:** Arithmetic, input/output

### 1️⃣0️⃣ Multiplication Table
Prints multiplication table for a given number.  
**Learned concepts:** Loops, formatting output

### 1️⃣1️⃣ Fibonacci Sequence Generator
Generates Fibonacci sequence up to n terms.  
**Learned concepts:** Loops, lists, arithmetic

### 1️⃣2️⃣ Simple Quiz Game
Multiple choice quiz with scoring.  
**Learned concepts:** Lists, conditionals, loops, input handling

### 1️⃣3️⃣ Countdown Timer
Counts down from a specified number of seconds.  
**Learned concepts:** Loops, `time` module, input

### 1️⃣4️⃣ Random Password Generator
Generates a random password of specified length.  
**Learned concepts:** Strings, random module, loops

### 1️⃣5️⃣ Rock–Paper–Scissors-Lizard-Spock (Optional Extension)
An extended version of RPS game with 5 options.  
**Learned concepts:** Conditionals, random module, loops
